# QuickMed destination and dashboard update

- On first dashboard entry after registration/login, QuickMed asks the user to save the current GPS coordinates as the default medication destination or choose another point on the map.
- The confirmation dialog displays the detected address, latitude and longitude before saving.
- Added Reset Destination to Quick Actions and More Options. Reset clears the saved coordinates and immediately starts destination setup again.
- Removed the central Scan Rx bottom-navigation action.
- Dashboard action tiles now use distinct colors, borders and soft backgrounds.
- Notification bell shows the number of received app notifications.
- Notification cards use tinted backgrounds and improved typography.
- Notifications can be deleted using the delete icon or swipe-left action.
